FAQ

Questions people ask

Is it free?

The code is free and MIT-licensed. Whether the hosted version has paid options isn’t decided yet.

When can I use it?

Critsource is in early development, and nothing is usable yet. Watch releases on GitHub to hear when the first feature ships.

Which rules does it cover?

The 2014 fifth-edition rules from the System Reference Document 5.1 (SRD 5.1), which Wizards of the Coast publishes under the Creative Commons Attribution 4.0 license. Material from other books isn’t included.

Is it official?

No. Critsource is an unofficial fan project and is not affiliated with Wizards of the Coast. Dungeons & Dragons and D&D are trademarks of Wizards of the Coast LLC.

Can I bring my homebrew?

Yes, that’s part of the plan. You’ll add your own spells, monsters, and items on top of the SRD 5.1 rules, and find them in the compendium next to the rest.

Can I run it on my own server?

That’s planned. The code is MIT-licensed, so you’re free to run your own copy once there’s an app to run. The hosted version gets the most support.

Who builds it?

One lead maintainer builds Critsource in the open on GitHub. Anyone can ask a question, suggest an idea, or report a bug in Discussions, and contributors who keep at it can become maintainers.
